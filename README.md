# 智能步数管理（HyperOS）

KernelSU / Magisk 模块：`S-T-E-P-S`

## 项目说明

此仓库用于存放智能步数管理模块源码、版本信息和发布包。

## 下载

正式安装包请前往 [Releases](https://github.com/xiaoji0308/Steps/releases) 下载。

## 在线更新

最新 Release API：<https://api.github.com/repos/xiaoji0308/Steps/releases/latest>

发布新版本时，请创建 GitHub Release 并附上可安装的模块 ZIP。WebUI 更新检查应读取该 Release 的版本、说明和附件下载链接。

## 注意

更新检查需要设备能够访问 GitHub；检查失败不应影响模块原有功能。
